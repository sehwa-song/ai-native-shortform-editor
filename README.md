# 🎬 AI Native Shortform Editor

> **참고 영상 URL과 자연어 요청을 바탕으로 숏폼 영상 제작·편집을 지원하는 AI Native 웹 에디터**
>
> WeGoYCombinator · 2026 AI Platform Build Challenge

## 📌 프로젝트 소개

기존 영상 편집은 컷 분할, 클립 배치, 자막 삽입처럼 반복되는 작업이 많고, 원하는 영상의 분위기와 구성을 재현하려면 상당한 시간이 필요합니다.

**AI Native Shortform Editor**는 사용자가 참고하고 싶은 영상의 URL과 편집 요청을 입력하면, AI가 영상의 내용·트렌드·편집 맥락을 분석하고 편집 작업을 도와주는 **숏폼 제작 웹 플랫폼**을 목표로 합니다.

이번 대회에서는 전문 편집기 전체를 구현하기보다 **작동하는 최소 기능 제품(MVP)** 에 집중합니다.

> **개발 상태:** 기획 및 기술 검토 단계. 아래 기능·구조는 목표 및 제안이며, 별도 표시가 없는 한 구현·동작 검증이 완료되었다는 의미가 아닙니다.

## 🎯 핵심 사용자 시나리오

1. 사용자가 참고할 **숏폼 영상 URL**을 입력합니다.
2. AI가 접근 가능한 참고 정보에서 **영상의 내용, 흐름, 편집 스타일**을 분석합니다.
3. 사용자가 자신의 영상 소스와 **자연어 편집 요청**을 제공합니다.
4. AI Agent가 요청을 **편집 작업 목록**으로 바꾸고 영상 편집 엔진에 전달합니다.
5. 사용자는 결과를 **미리보기·수정**한 후 영상 파일로 내보냅니다.

참고 URL의 수집·분석 범위는 플랫폼별 접근 권한, 저작권 및 API 제한을 검토한 뒤 결정합니다.

| 우선순위 | 영역 | 목표 기능 | 상태 |
| --- | --- | --- | --- |
| P0 | 웹 편집기 | 영상 파일 불러오기, 타임라인 표시, 클립 배치 | 예정 |
| P0 | 기본 편집 | 자르기·분할, 영상 미리보기 | 예정 |
| P0 | 결과 출력 | 편집 결과 MP4 내보내기 | 예정 |

| P0 | 참고 영상 | URL 입력 및 스타일·구성 분석 가능한 범위 검증 | 검토 중 |
| P1 | 편집 자동화 | 자막, 무음 구간 정리, 오디오·속도 조정 | 후보 |

## 🔁 서비스 동작 구조 (목표)

```text
[사용자]
   ├─ 참고 영상 URL 입력
   ├─ 영상 소스 제공
   └─ 자연어 편집 요청
              ↓
[웹 프론트엔드]
              ↓
[백엔드 / 작업 제어]
   ├─ 참고 영상 분석 모듈 (접근 가능 범위 내)
   └─ AI Agent (의도 해석 · 편집 작업 계획)
              ↓
[편집 명령 / 실행 엔진]
   ├─ 클립 자르기·분할·배치
   ├─ 타임라인·미리보기 갱신
   └─ 렌더링·MP4 내보내기
              ↓
[사용자 결과 확인 및 수정]
```

### AI Native 설계 원칙

- **반복·규칙 기반 작업**은 편집 엔진이 처리하고, **판단이 필요한 작업**에 AI Agent를 활용합니다.
- AI가 실제 편집을 수행할 수 있도록 **명령 실행 경로**를 분리합니다.
- 불필요한 LLM 호출과 토큰 사용을 줄이고, 실행 결과를 사용자가 확인할 수 있도록 설계합니다.

## 🔬 기술 조사 및 선택 예정 영역

현재 구체적인 언어·프레임워크·배포 스택은 **최종 확정 전**입니다.

| 영역 | 검토 대상 |
| --- | --- |
| 웹 영상 편집 | OpenCut Classic 등 오픈소스 편집기 구조·재사용 가능성 |
| 브라우저 영상 처리 | Canvas, WebCodecs, WASM, Mediabunny 등 |
| 편집 기능 | 타임라인, 클립 분할, 미리보기, MP4 Export 파이프라인 |
| AI 자동화 | Agent의 자연어 명령 해석, 편집 명령 구조, 외부 API 연동 |
| 조사·검증 | REA를 이용한 동작 분석 및 구현 가능성 조사 |

오픈소스를 활용할 경우 라이선스와 실제 동작을 검증한 뒤 채택합니다. 기존 서비스와 공개 프로젝트의 코드 관계는 확인되지 않은 추정을 사실로 전제하지 않습니다.

## 🚀 개발 로드맵

- [ ] **1단계 — 기반 구축:** 저장소·브랜치·프로젝트 실행 환경 및 기본 웹 화면
- [ ] **2단계 — 기본 편집:** 영상 입력, 타임라인, 컷 편집, 미리보기, MP4 출력
- [ ] **3단계 — AI 연동:** 자연어 편집 요청 → 명령 생성 → 편집 엔진 실행
- [ ] **4단계 — URL 시나리오:** 참고 영상 분석과 유사 스타일 편집 흐름 연결
- [ ] **5단계 — 통합 검증:** 입력부터 출력까지 E2E 테스트, 오류 수정, 데모
- [ ] **6단계 — 사용성 평가:** 제작 시간·작업량·사용자 피드백 측정
